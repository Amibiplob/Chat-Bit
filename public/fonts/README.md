# Bundled ChatBit fonts

These are the original variable Latin subsets of Inter (100–900) and JetBrains
Mono (100–800), preserved from the project's successful Next.js Google Fonts
build output. They are unchanged WOFF2 assets, now loaded with `next/font/local`.
Other scripts use browser fallback fonts. No network fetch is needed at build time.

Sources and licensing:
